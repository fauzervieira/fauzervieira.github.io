Aplicativo de Controle Financeiro Pessoal

Automação, classificação e inteligência financeira com Python.

Aplicação desenvolvida a partir da evolução do projeto de Controle Financeiro Pessoal em Power BI, com o objetivo de automatizar processos de importação, classificação, validação e preparação dos dados financeiros.

Python Tkinter Pandas Excel Power BI Automação
Origem

Como o Projeto Evoluiu

O ponto de partida

O projeto começou como um dashboard financeiro desenvolvido no Power BI. Conforme novas regras de classificação, validação e atualização foram sendo adicionadas, parte do processo passou a exigir automação.

A evolução

A solução evoluiu para uma aplicação em Python capaz de centralizar etapas operacionais do processo financeiro, preparar dados para análise e reduzir tarefas manuais recorrentes.

Estrutura

Arquitetura da Aplicação

O aplicativo funciona como uma camada de processamento entre os arquivos financeiros e as ferramentas de análise.

Funcionalidades

Principais Recursos

Importação de Dados

Processamento dos arquivos financeiros utilizados na rotina de atualização do sistema.

Padronização

Conversão de descrições bancárias em lançamentos padronizados para facilitar classificação e análise.

Classificação Automática

Aplicação de regras para tipo financeiro, nicho, subnicho e contexto de classificação.

Identificação de Pendências

Registros não reconhecidos são separados para revisão e posterior incorporação às regras do sistema.

Fluxo Financeiro Futuro

Processamento de informações para projeções, compromissos futuros e necessidade de caixa.

Integração com Power BI

Geração de bases estruturadas utilizadas pelo relatório analítico do projeto.

Privacidade e proteção dos dados

As telas apresentadas nesta versão pública utilizam dados sintéticos e demonstrativos. Informações financeiras reais, dados pessoais, instituições, fornecedores e demais elementos identificáveis foram preservados, seguindo boas práticas de privacidade e os princípios de proteção de dados previstos na LGPD.
